SEMPER – Referencje OCR v0.3.10

NOWOŚCI v0.3.10:
- „Zaktualizuj referencje” wpisuje domyślnie bieżącą datę RRRR-MM-DD do pola Sortowanie i zapisuje natywny formularz.
- Pole „Po zapisie” jest widoczne obok Sortowania, domyślnie pokazuje dzisiejszą datę i można je zmienić ręcznie.
- Naprawiono błąd, przez który ukrycie sekcji „Tekst” mogło schować zbyt duży fragment natywnego formularza.
- Widoczne pozostają m.in. * Aktywne i * Sortowanie; zbędne Nazwa, Alias i Zdjęcie są ukrywane.
- Natywna miniatura „Podgląd zdjęcia” jest ukrywana.
- Natywna sekcja „Tekst”/CKEditor jest ukrywana precyzyjnie.
- W ich miejscu wtyczka dodaje sekcję „Podgląd oryginału:” z pełnowymiarowym plikiem referencji i linkiem „Otwórz oryginał”.

INSTALACJA / AKTUALIZACJA:
1. Rozpakuj ZIP.
2. Otwórz chrome://extensions.
3. Włącz Tryb dewelopera.
4. Jeżeli podmieniasz folder poprzedniej wersji – kliknij „Odśwież” przy rozszerzeniu.
5. Przy nowej instalacji kliknij „Załaduj rozpakowane” i wskaż folder semper_referencje_ocr_mv3_v0.3.10.
